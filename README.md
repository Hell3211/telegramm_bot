# Telegram Bot - Здарова! 🤖

Простой и дружелюбный Telegram-бот для всех!

## Возможности

- ✅ Команда `/start` - приветствие
- ✅ Команда `/help` - справка
- ✅ Команда `/about` - информация о боте
- ✅ Команда `/echo` - повтор сообщения
- ✅ Обработка обычных сообщений
- ✅ Умные ответы на популярные фразы

## Настройка

### Получи токен бота

1. Откройте Telegram
2. Найдите бота **@BotFather**
3. Отправьте команду `/newbot`
4. Следуйте инструкциям
5. Скопируйте полученный токен

### Добавь токен в код

Отредактируй файл `bot.py` и замени:

```python
TOKEN = "YOUR_BOT_TOKEN_HERE"
```

На твой реальный токен:

```python
TOKEN = "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
```

## Запуск

```bash
python bot.py
```

Ты увидишь сообщение:
```
🤖 Бот запущен!
```

## Использование

Откройте Telegram и найдите своего бота по имени, которое ты указал при создании.

Доступные команды:
- `/start` - начать диалог
- `/help` - справка
- `/about` - информация о боте
- `/echo текст` - повтор текста

Также можно просто писать сообщения, и бот будет отвечать! 💬

## Безопасность

**ВАЖНО:** Никогда не делись своим токеном с другими людьми! 🔐

## Требования

- Python 3.8 или выше
- Интернет-соединение
- Учетная запись Telegram

## Устранение проблем

**Ошибка: "Токен неверный"**
- Проверь, правильно ли ты скопировал токен
- Убедись, что нет пробелов в начале или конце

**Бот не отвечает**
- Проверь интернет-соединение
- Убедись, что скрипт запущен (看 сообщение "🤖 Бот запущен!")
- Перезагрузи скрипт
