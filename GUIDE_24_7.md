# Гайд: Запуск бота 24/7 на Windows

## Вариант 1: Планировщик задач (самый простой) ⭐

1. **Нажми** `Win + R` и введи `taskschd.msc`
2. **Справа** нажми "Создать базовую задачу"
3. **Имя:** `Telegram Bot`
4. **Триггер:** "При запуске системы"
5. **Действие:** "Запустить программу"
   - Программа: `python.exe`
   - Аргументы: `c:\Users\bilol\OneDrive\Desktop\telegramm_bot\bot.py`
   - Начальная папка: `c:\Users\bilol\OneDrive\Desktop\telegramm_bot`
6. **Галочки:**
   - ☑️ Запустить с наивысшими привилегиями
   - ☑️ Выполнить независимо от входа пользователя
7. **Готово!** Бот запустится при включении ПК

## Вариант 2: Windows Service с NSSM (более надежный) 🔧

1. **Скачай NSSM:** https://nssm.cc/download
2. **Распакуй** в папку проекта: `telegramm_bot\nssm`
3. **Запусти PowerShell как администратор**
4. **Выполни:**
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   c:\Users\bilol\OneDrive\Desktop\telegramm_bot\install_service_nssm.ps1
   ```
5. **Готово!** Бот будет работать как служба 24/7

## Вариант 3: Облако ☁️ (лучше всего для надежности)

Скачай бота на облачный сервер (VPS):
- **Heroku** (бесплатно, но медленно)
- **AWS** (платно, но надежно)
- **DigitalOcean** ($5/месяц)
- **Хостинг на дешевый VPS** в России/Беларусь

## Проверка статуса

**На планировщике задач:**
- Правый клик на задачу → "Просмотреть журнал"

**На Windows Service:**
```powershell
Get-Service -Name TelegramBot
```

## Остановка/Перезагрузка

**Планировщик:** Отключи задачу в планировщике
**Service:** 
```powershell
Stop-Service -Name TelegramBot
Start-Service -Name TelegramBot
```

---

**Совет:** Используй Вариант 1 (Планировщик) если хочешь просто и быстро.
Используй Вариант 2 (NSSM) если нужна максимальная надежность на ПК.
Используй Вариант 3 (Облако) если нужен 100% аптайм.
